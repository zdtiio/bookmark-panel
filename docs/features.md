# 功能说明

## 1. 未登录首页

未登录时展示 `GuestView`：

- 大号时钟与日期，每秒更新。
- 搜索框，可选择百度 / Google / Bing，回车后跳转到对应搜索引擎。
- 「登录」「注册」按钮，切换到对应页面。

注册成功后会自动登录，并为新用户创建一个名为「默认文件夹」的文件夹。

## 2. 登录后的两种视图

登录后顶部栏提供视图切换：

| 视图 | 说明 |
| --- | --- |
| 首页 | 自定义看板，只展示收藏到首页的书签和文件夹 |
| 管理 | 完整的文件夹侧栏、书签列表、搜索、编辑和批量操作 |

首次进入默认是「首页」。首页为空时会显示引导，点击「去管理」进入管理视图。

## 3. 自定义首页

首页看板由配置项 `homeItems` 驱动，数组元素格式为：

```json
{ "type": "bookmark", "id": 12 }
```

或：

```json
{ "type": "folder", "id": 3 }
```

行为：

- 书签卡片：点击在新标签页打开链接。
- 文件夹卡片：切换到管理视图并选中该文件夹，同时在侧栏中展开其父级路径。
- 拖拽卡片可调整顺序，顺序立即保存到 `homeItems`。
- 卡片右上角可移除；移除只影响首页展示，不会删除书签或文件夹。
- 首页看板不展示侧栏，适合作为日常快捷入口。
- 每次加载用户数据时，会清理指向已删除书签/文件夹的 `homeItems` 记录。

在管理视图中，可以通过书签卡片和文件夹卡片上的首页按钮，把条目加入或移出首页。

## 4. 管理视图

### 4.1 侧栏默认收起

- `sidebarCollapsed` 初始值为 `true`，因此进入管理视图时文件夹侧栏默认隐藏。
- 侧栏隐藏时，左上角显示一个「显示侧栏」按钮。
- 移动端展开侧栏会显示半透明遮罩，点击遮罩或选中文件夹后自动收起。
- 如果配置项 `showFolders` 为 `false`，侧栏和切换按钮都不显示。

### 4.2 文件夹树

- 文件夹支持无限层级，字段为 `parentId`。
- 同一层级按 `sortOrder` 升序、再按名称排序。
- 侧栏支持展开/收起、重命名、删除，以及把文件夹拖到另一个文件夹下改变父级。
- 删除限制：文件夹下存在子文件夹或书签时不允许删除，接口会返回错误。
- 新建文件夹时，`sortOrder` 取同级最大值加一；弹窗默认以当前所在文件夹作为父级。

### 4.3 面包屑与根目录

书签区域顶部显示当前路径，第一项固定为「全部书签」：

- 点击「全部书签」会把 `selectedFolderId` 设为 `null`，回到根目录，展示所有书签和顶层文件夹。
- 点击路径中的任意文件夹可跳转到该层级。
- 路径由当前文件夹不断向上查找 `parentId` 生成，因此会完整展示多级目录。

### 4.4 书签展示与操作

- 根目录展示全部书签；选中文件夹后只展示该文件夹下的书签。
- 顶部同时展示当前层级的子文件夹卡片。
- 支持添加、编辑、删除书签。
- 添加书签弹窗会默认选中当前所在的文件夹，可再手动切换。
- 支持拖拽书签调整顺序，顺序写入 `sortOrder`。
- 支持进入编辑模式后多选书签，批量移动到其他文件夹或批量删除。
- 书签卡片展示 `icon`；未设置图标时显示标题首字母色块，配置项 `showIcons` 控制是否展示。
- 后端提供 `POST /api/bookmarks/icon` 图标上传接口；当前添加/编辑弹窗尚未内置图标上传控件。
- 点击书签卡片在新标签页打开链接。

### 4.5 搜索

- 搜索框输入后调用 `GET /api/bookmarks/search?q=`。
- 在标题、URL、描述三个字段中做模糊匹配。
- 搜索期间管理视图只展示搜索结果，不展示子文件夹。
- 清空搜索后恢复当前文件夹视图。

## 5. 设置面板

设置保存在后端配置表中，并同步缓存到浏览器 `localStorage`。

### 5.1 外观

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| `siteName` | 浏览器标题和界面站点名称 | `Bookmark-Panel` |
| `backgroundType` | `color` 或 `image` | `color` |
| `backgroundColor` | 纯色背景 | `#1a1a2e` |
| `backgroundImage` | 背景图片 URL | 空 |
| `showIcons` | 是否展示书签图标 | `true` |
| `showFolders` | 是否展示文件夹侧栏 | `true` |
| `defaultFolderId` | 默认文件夹，同时用于插件添加书签时的默认目标 | `null` |

### 5.2 搜索

内置 Google、百度、Bing，也可以选择「自定义」并填写带查询参数的 URL 前缀，例如：

```text
https://example.com/search?q=
```

保存时若选择自定义，会把 `searchEngine` 写成实际 URL 前缀。

### 5.3 API Token

- 可以创建多个 Token，用于不同设备或客户端。
- 创建或轮转后明文只显示一次，请立即复制保存。
- 列表展示名称、创建时间、最后使用时间。
- 支持删除和手动轮转；轮转后旧 Token 立即失效。

### 5.4 数据备份

- 导出用户数据：`GET /api/config/export`，返回包含用户信息、书签、文件夹和配置的 JSON 文件。
- 导入用户数据：`POST /api/config/import`，使用 `multipart/form-data`，字段名为 `file`，仅接受 JSON，大小上限 10 MB。
- 导入采用合并策略：按名称和父级匹配文件夹，按 URL 去重书签，配置项覆盖写入。

### 5.5 书签导入导出

- 支持 HTML（Chrome/Edge 通用 Netscape 格式）、Chrome JSON、Firefox JSON。
- 导入前必须选择目标文件夹；导入过程会按 HTML 中的文件夹路径自动创建子文件夹。
- 同一用户下已存在的 URL 会跳过，不会重复创建。
- 导出支持 `format=html|chrome|firefox`，默认 `html`。

## 6. 浏览器插件联动

- 插件保存书签时使用 `X-API-Token`，不依赖网页登录态。
- 插件打开面板时通过 URL hash 携带 API Token，面板自动换取 JWT 并清理地址栏。
- 插件的新标签页在配置了 API URL 和 Token 后，会直接跳转到书签面板。
- 插件弹窗会读取 `defaultFolderId`，作为添加书签时的默认文件夹。

详细说明见 [extension.md](./extension.md)。

## 7. 已知限制

- 管理视图会一次性加载当前用户的全部书签，再在前端过滤；没有服务端分页或虚拟滚动，书签数量很大时首屏和滚动性能会下降。
- Chrome/Firefox JSON 导入只记录最近一层文件夹名，无法完整还原多层目录；HTML 导入可以保留层级。
- 书签导出按文件夹名称分组，只输出一层文件夹结构，深层级会被压平。
- 「数据备份」设置页的历史实现仍请求 `/api/configs/*`，而后端实际路径是 `/api/config/*`。在页面修复前，请直接调用后端实际接口完成备份/恢复。
- 插件新标签页的搜索固定使用 Google，不读取面板中的 `searchEngine` 配置。
- 插件快捷方式会打开预填当前页面的「添加书签」页，而不是静默直接保存。
- `app.js` 中创建的 `node-cache` 实例当前未接入业务查询。
